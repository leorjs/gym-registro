# Third-party exercise assets

## Workout Guide

The gym-only Workout Guide illustrations displayed by this application are loaded unchanged from
[`bryllim/workout-guide`](https://github.com/bryllim/workout-guide), commit
`aac599224bb9780305239607ef98540b7e0ce389`.

- Expanded exercise artwork and animation frames: Bryl Lim.
- Original pose artwork: Everkinetic.
- License: [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).
- Changes made by this application: no changes to the SVG artwork; the three original frames are displayed sequentially to create an animation.

The application intentionally imports only exercises associated with gym equipment. Home-only exercises,
stretches, pull-ups, chin-ups and dips are excluded from the Workout Guide subset.
